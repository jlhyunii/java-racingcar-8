# java-racingcar-precourse

#### 자동차 경주 게임
<br>

### 1. 자동차 이름 입력 기능
- 사용자로부터 경주할 자동차 이름들을 입력받는다.
  - `camp.nextstep.edu.missionutils.Console`의 `readLine()` 사용
  - 입력 전 `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)`을 출력
  - 입력받은 문자열을 쉼표(,) 기준으로 분리
- 각 이름에 대해 입력값 검증을 수행한다.
  - 5자 초과 불가
  - 공백 포함 불가
  - 빈 문자열 불가
  - 중복 이름 불가
  - 쉼표(,) 외의 구분자 사용 불가
- 유효한 이름 목록을 `Car` 객체 리스트로 변환한다.

### 2. 시도 횟수 입력 기능
- 사용자로부터 시도할 횟수를 입력받는다.
  - `camp.nextstep.edu.missionutils.Console`의 `readLine()` 사용
  - 입력 전 `시도할 횟수는 몇 회인가요?`를 출력
- 입력값 검증을 수행한다.
  - 비어있는 입력 불가
  - 숫자가 아닌 입력 불가
  - 0 이하의 값 불가
- 유효한 입력값을 정수로 변환해 반환한다. -> 사용자 입력이 문자열이기 때문.

### 3. 경주 게임 기능
- 각 자동차별로 한 번의 시도를 수행한다.
  - 0~9 사이의 랜덤 값을 생성
  - 랜덤 값이 4 이상일 경우 전진
- 입력받은 시도 횟수만큼 반복 실행한다.
- 각 시도마다 자동차들의 전진 결과를 출력한다.

### 4. 우승자 판별 기준
- 모든 자동차 중 최종 전진 거리가 가장 큰 값을 찾는다.
- 최대 거리가 같은 위치의 자동차들을 우승자로 선정한다.
- 우승자가 여러 명일 경우 쉼표(,)로 구분하여 출력한다.

### 5. 출력 기능
- 각 시도별 실행 결과를 콘솔에 출력한다.
- 최종 우승자 안내 문구를 출력한다.
